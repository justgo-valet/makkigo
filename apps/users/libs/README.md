# libs

**서버와 브라우저가 함께 쓰는 코드**와 공통 도구입니다.

| 폴더                  | 넣는 것                                                                                              |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| `<도메인>/contracts/` | API 요청 · 응답 형식(zod 스키마와 타입), 오류 코드. `app/api/` 와 `features/` 가 같은 파일을 씁니다. |
| `common/api/`         | 브라우저용 API 클라이언트 `apiClient` (`/api/v1`, 토큰 재발급, 시간 초과)                            |
| `common/format/`      | 값 형식 변환 (예: `formatPhoneNumber`)                                                               |

## 규칙

- contracts 는 서버에서도 실행되므로 브라우저 전용 코드(`window`, React)를 넣지 않습니다.
- 폼 검증 스키마는 contracts 가 아니라 `features/<도메인>/schemas/` 에 둡니다. 화면 문구가 붙고 서버는 쓰지 않기 때문입니다.
- 필수 약관처럼 서버 규칙이 기준인 값은 contracts 에 한 번만 정의하고 화면은 거기서 계산합니다 (`isRequiredConsent`).
- 도메인 이름은 `server/<도메인>/` 과 맞춥니다.
