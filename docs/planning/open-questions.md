## 기획

| 항목 | 현재 상태 | 영향 |
|---|---|---|
| 계약 업체가 2곳 이상인 부스에, 도착 알림 없이 온 **회원** | 업체를 알 수 없어 티켓 없음. 그대로 둠 | 티켓만 못 봄 (출차 요청은 됨) |
| 도착 알림 후 고객이 오지 않음 | 도착 예정 상태로 계속 남음 | 요원 목록에 쌓임 |
| 로그인 유지 30일의 갱신 기준 | 지금은 **마지막으로 쓴 때부터 30일**: 액세스 토큰(15분)이 만료된 뒤 앱을 열거나 API 를 부르면 리프레시 토큰을 새로 받아 다시 30일 (decisions 2026-11-06, #249). 피드백(2026-11-08)은 "로그인 시점부터 30일" — 로그인 시점 고정으로 바꿀지 결정 필요 | 고정으로 바꾸면 매일 쓰는 사람도 30일마다 다시 로그인 |
| 출차 요청 취소 | 기능 없음 | |
| 비회원에게 실제 요금 · 출차 준비 알리기 | 전화번호가 없어 푸시 · 알림톡 불가. QR 로 연 화면에서만 보여줄지 미정 | 비회원 출차 ([시나리오 D](valet-scenarios.md#d-비회원--앱-없이-옴)) |
| 약관 확정 | 2026-10-16 법률 검토 반영. 빈칸: 대표 전화번호 · 알림톡 대행사 · 위치정보관리책임자 · 위치기반서비스 신고번호. 변호사 검토 → [legal/README.md](../legal/README.md) | 동의 화면 · 처리방침 |
| 위치기반서비스사업 신고 · 위치정보관리책임자 | 회사가 진행. 신고 처리 기간 확인 필요 → [legal/README.md](../legal/README.md#위치정보) | 위치 동의 · 예상 도착 시각 출시 |
| 티켓 디자인 저장 형식 | JSON 컬럼 자리만 둠 | 티켓 편집기 구조가 정해져야 함 |

## 개발

| 항목 | 현재 상태 |
|---|---|
| 약관 · 개인정보 관련 미구현 | 요원 앱 동의 · 로그인 화면 약관 링크, 비회원 동의 기록 저장(비회원 API 와 함께), 앱 접근 권한 안내, 애플 토큰 암호화, DB 접속 기록 → [legal/README.md](../legal/README.md#2026-10-16-검토-뒤-남은-할-일) |
| 요원 탈퇴와 동시에 온 도착 알림 | 고객 도착 알림은 업체 · 부스 확인을 트랜잭션 밖에서 하고 길찾기 API 를 기다린 뒤 세션을 만듦. 그 사이 부스 관리자 · 업체 관리자가 탈퇴하면 처리할 부스가 없는 도착 예정 세션과 탈퇴 요원 앞 알림이 남을 수 있음. 막으려면 도착 알림 트랜잭션에서 업체 · 부스 행을 `FOR SHARE` 로 잠그고 다시 확인 |
| 알림톡 연동 | 발송 코드 없음. 정책은 푸시를 못 받으면 알림톡으로 보낸다고 함. 연동 전에 휴대폰 번호 인증 여부 결정 필요 |
| Play 비공개 테스트 | 10/7 시작 계획이 지남. 시작 여부와 10/31 출시 영향 확인 → [mobile.md](../architecture/mobile.md#빌드--서명) |
| DB 백업 | DB 가 서버 안 컨테이너라 백업(정기 덤프 → S3 등)을 직접 해야 함 |
| 카카오톡 앱으로 간편 로그인 (요원 앱) | 고객 앱은 SDK 로그인(2026-10-19)으로 카카오톡 앱으로 바로 감. 요원 앱은 아직 시스템 브라우저 창 방식이라, 창에서 카카오톡 앱 전환이 되는지 실기기 확인 필요. 안 되면 아이디 · 비밀번호 로그인만 |
| 카카오 로그인 오류 (고객 앱, 2026-11-06 22:00경 보고) | 원인 미확인. 기기 · OS · 화면 문구 확인 후 [runbook](../operations/runbook.md#문제가-생겼을-때)의 "고객 앱(SDK) 로그인이 안 됨" 순서로 서버 로그 확인. 같은 날 21:14 에 로그인 유지 수정(#249)이 main 에 머지됐지만, 이 수정은 로그인 표시 쿠키가 있는 **페이지** 요청만 바꾸고 로그인 API(`/api/…`)는 건드리지 않음 |
| 인증 API 요청 횟수 제한 | 없음. 출시 전 검토 |
| 카카오모빌리티 길찾기 무료 한도(하루 1만 건) 초과 대비 | 넘으면 그날 길찾기가 막혀 "도착 시간 미정". 하루 1만 건에 가까워지면 제휴 계약(건당 8원) |
| 업체 좌표 | 좌표가 비어 있으면 첫 도착 알림 때 주소로 찾아 저장(별도 스크립트 없음). 주소가 검색되지 않는 업체는 예상 시각이 계속 미정이라, 업체 등록 화면이 생기면 등록 때 좌표 확인 필요 |
