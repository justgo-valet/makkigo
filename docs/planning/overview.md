# 서비스 개요

디지털 발렛파킹 서비스. 고객은 차를 맡기고 찾을 때 앱(또는 QR 로 연 웹)에서 상태를 보고 출차를 요청하고, 발렛 요원은 앱에서 차량을 관리합니다.

## 앱 구성

| 앱 | 쓰는 사람 | 위치 |
|---|---|---|
| 고객 앱 | 회원 고객, 비회원 고객(QR → 브라우저) | `apps/users` |
| 요원 앱 | 발렛 요원, 부스 관리자 | `apps/valetagents` (`valet.makkigo.com`) |
| 업체 관리자 포털 | 업체 관리자 (티켓 디자인 · 업체 정보 · QR · 발렛 현황) | `apps/tickets` (`tickets.makkigo.com`, 웹만) |
| 슈퍼 어드민 콘솔 | 슈퍼 어드민 (업체 · 업체 관리자 계정 · 부스 연결 관리) | `apps/admin` (`admin.makkigo.com`, 웹만) |

- 고객 앱 · 요원 앱 웹은 Next.js, 모바일 앱은 **Flutter 웹뷰**로 감쌉니다. 소셜 로그인은 Next.js 서버가 OAuth 로 처리하고 앱은 시스템 브라우저 창만 열어 줍니다. 푸시는 Flutter 네이티브가 처리합니다. → [auth.md](../architecture/auth.md)
- 업체 관리자 포털 · 슈퍼 어드민 콘솔은 컴퓨터 브라우저용 관리 화면입니다(Figma 없음, `packages/ui` 의 shadcn 컴포넌트).

## 용어

| 용어 | 뜻 |
|---|---|
| **발렛 요원** | 차를 받아 주차하고 출차하는 사람. 앱에서는 "기사"가 아니라 **"요원"** 이라고 부릅니다. |
| **발렛 부스** | 발렛을 운영하는 단위. 요원이 소속되고, 요금 기준표와 입금 계좌를 설정합니다. |
| **부스 관리자** | 별도 계정 유형이 아니라 **부스를 만든 요원**입니다. 요원 등록과 업체 계약을 승인합니다. |
| **업체** | 식당·호텔 등 고객이 방문하는 곳. 부스와 계약합니다. 업체에 QR 이 붙어 있습니다. |
| **업체 관리자** | 업체 하나에 연결된 아이디 · 비밀번호 계정. 업체 관리자 포털에서 티켓 디자인을 만들고 업체 정보 · QR · 발렛 현황을 봅니다. 업체를 직접 등록하지 않고, 계정은 슈퍼 어드민이 만들어 줍니다. 한 업체에 계정이 여럿일 수 있습니다. |
| **슈퍼 어드민** | 운영사 계정. 업체를 미리 모두 등록하고, 업체 관리자 계정을 만들어 업체와 연결하고, 업체와 부스의 연결을 요청합니다. 계정은 화면 · 스크립트 없이 DB 담당자가 직접 관리합니다 → [runbook.md](../operations/runbook.md#슈퍼-어드민-계정) |
| **발렛 세션** | 한 번의 맡김~찾음. → [valet-session.md](valet-session.md) |
| **티켓** | 업체가 디자인한 발렛 티켓. 홍보 문구가 디자인에 포함됩니다. |

"운전기사" 역할은 없습니다 (Figma 에 남아 있지만 무시).

## 관계

```
요원 ──소속──▶ 부스 ◀──계약(N:M)──▶ 업체 ──▶ 티켓
                │                      │
          요금 기준표, 입금 계좌       QR
```

- 업체 하나가 여러 부스와 계약할 수 있습니다.
- 도착 알림은 그 업체와 계약한 **모든 부스의 요원**에게 가고, 부스는 실제로 주차 처리한 요원의 부스로 정해집니다.

## 회원과 로그인

| 유형 | 로그인 |
|---|---|
| iOS 고객 | 카카오 · 구글 · 애플 |
| Android 고객 | 카카오 · 구글 |
| 비회원 고객 | 로그인 없음. 업체 QR 로 브라우저 접속 |
| 요원 | 고객과 같은 소셜 로그인 → 파트너 약관 동의 → 요원(역할 선택 화면 없음) |
| 업체 관리자 | 아이디 · 비밀번호 (슈퍼 어드민이 발급한 임시 비밀번호 → 첫 로그인 때 변경) |
| 슈퍼 어드민 | 아이디 · 비밀번호 |

## 1차 MVP 제약 (이후 완화 예정)

- 회원 1명당 차량 1대, 차량 번호 하나는 회원 1명만 등록
- 업체 관리자 계정 하나는 **업체 하나**에만 연결
- 업체 관리자는 업체 정보를 고치지 못함(보기만). 고칠 일이 있으면 슈퍼 어드민에게 요청
- 결제 연동(PG) 없음 — 계좌이체 안내만 → [policies.md](policies.md)
