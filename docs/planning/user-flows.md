# 고객 플로우

처음 기획 문서(`user-readme.md`)를 옮기고, 이후 결정으로 바뀐 부분은 **(변경)** 으로 표시했습니다.
화면은 [screens.md](../design/screens.md), 세션 규칙은 [valet-session.md](valet-session.md) 참고.

## 회원가입 · 로그인

1. 소셜 로그인 (iOS: 카카오·구글·애플 / Android: 카카오·구글·네이버)
2. 처음 가입이면 온보딩 진행
   1. **약관 동의 (변경: 추가)** — 차량 번호 화면 위에 바텀시트로. 필수 4개(만 14세 이상 · 이용약관 · 개인정보 수집 · 이용 · 제3자 제공), 선택 3개(앱 푸시 · 알림톡 · 위치기반서비스), 전체 동의. 필수를 모두 체크해야 "동의하고 시작하기". → [policies.md](policies.md)
   2. 차량 번호 입력
   3. 휴대폰 번호 입력
   4. 브랜드(제조사) 선택, 없으면 직접 입력
   5. 차량 모델 선택, 없으면 직접 입력
3. 메인 페이지

온보딩 완료 = 휴대폰 번호와 차량이 모두 있음. 소셜 가입만 한 상태는 미완료입니다.

## 업체 검색

1. 메인 → 업체 검색 버튼 (바텀시트)
2. 업체명으로 검색 → 선택
3. 발렛 요원에게 도착 알림을 보낼지 선택 (바텀시트) → 도착 알림 플로우 또는 완료

- 검색 대상은 **승인된 부스 계약이 있는 업체**만 (도착 알림을 받을 요원이 있는 곳). 업체명 · 주소로 찾고, 입력하면 바로 검색합니다. 검색어가 비면 안내 문구만 보여줍니다.
- 고른 업체는 **기기에만 저장**합니다 (DB 저장 없음). 도착 알림 전이면 메인에 그 업체명이 "도착 알림 전"으로 보입니다. 다시 고르면 바뀌고, 선택 해제는 없습니다.

## 도착 알림

1. 메인 → 도착 알림 버튼
2. 업체를 선택하지 않았으면: "업체가 선택되지 않았어요. 업체 검색을 하시겠어요?" → 업체 검색 플로우
3. 업체를 선택했으면: 도착 알림 전송 여부 선택 (바텀시트)
4. 보내기
   1. **(변경: 추가)** 위치기반서비스에 동의하지 않았으면 위치 동의 바텀시트 → 동의하고 보내기 / 동의 안 하고 보내기
   2. 동의했으면 현재 위치를 한 번 받음 (처음이면 OS 위치 권한 팝업)
5. 그 업체와 계약한 부스의 모든 요원에게 알림. 세션이 **도착 예정**으로 생기고, 위치를 받았으면 **예상 도착 시각**이 함께 요원 화면에 보입니다. 못 받았으면 "도착 시간 미정" → [policies.md](policies.md#위치정보)

**도착 알림 취소** 기능이 필요합니다 (처음 기획에 없던 내용, 서비스에 꼭 필요).

## 지연 알림

1. 메인 → 지연 알림 버튼
2. 도착 알림을 보내지 않았으면: "도착 알림을 먼저 해주세요" → 도착 알림 플로우
3. 보냈으면: 몇 분/시간 지연되는지 선택 → 지연 알림 보내기

## 출차 요청

1. 메인 → 출차 요청 버튼
2. **(변경)** 진행 중인 세션이 없으면: "도착 알림 없이 바로 요원님께 맡기셨나요? 요원님께서 주차 중입니다" 안내
   - 처음 기획은 "업체가 선택되지 않은 경우"였지만, 업체를 몰라도 출차 요청은 부스로 보낼 수 있어서 조건을 바꿨습니다.
3. 세션은 있는데 주차 완료가 아니면: "아직 주차 완료되지 않은 차량입니다"
4. 주차 완료면
   1. 발렛 요금 계산 내역 (기준표 요금) → 확인
   2. 출차 요청 접수 → 확인
5. 요원이 출차 응답하면 **실제 요금과 예상 출차 시각 알럿** (화면 미정)

출차 요청 취소 기능은 없습니다.

## 발렛 티켓 보기

메인 → 발렛 티켓 보러가기 → 발급된 티켓이 있으면 노출, 없으면 "현재 발급받은 발렛티켓이 없습니다".
업체를 모르는 세션은 티켓이 없습니다. → [open-questions.md](open-questions.md)

## 알림 내역

메인 → 종 아이콘 → 바텀시트에서 알림 내역 조회

## 마이페이지

메인 → 사람 아이콘 → 마이페이지
- 내 정보 수정 (차량 번호, 휴대폰 번호)
- 앱 푸시 · 알림톡 동의/미동의
- 로그아웃 (이 기기만), 회원 탈퇴

## 비회원 출차 요청

1. 업체에 붙은 QR 로 브라우저 접속 (QR 에 업체 정보가 있음)
2. 티켓 화면 — 차량 번호 입력 전에는 **그 업체의 가장 최신 티켓**
3. 출차 요청 버튼 → 차량 번호 입력
4. 출차 요청 접수. 이때 세션에 업체가 없었으면 **업체를 연결**하고, 차량 번호 입력 후에는 그 세션의 티켓을 보여줍니다.

QR 은 **업체 QR 한 종류**만 씁니다.

## 요원 쪽 (고객 플로우와 맞물리는 부분)

- 도착 예정 차량은 목록에서 **눌러서 바로 주차 처리** (인수 버튼 없음)
- 도착 알림 없이 온 차는 요원이 **주차한 뒤 차량 번호를 입력**해 세션을 만듭니다. 그 번호로 가입한 회원이 있으면 자동 연결
- 출차 요청이 오면 **출차 응답** — 실제 요금과 예상 출차 시각 지정
- 차를 건네면 **출차 완료** 처리
